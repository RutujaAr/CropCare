# 🌾 CropCare

## Crop Disease Information & Management Portal

CropCare is a simple educational web application that provides
information about selected crop diseases, including symptoms,
favorable conditions, management and prevention practices.

The project was developed as part of a Cloud Computing Honors
assignment focused on automated CI/CD deployment.

---

## Features

- Crop-based disease browsing
- Disease search
- Disease filtering by crop
- Disease information cards
- Symptoms information
- Favorable conditions
- Management information
- Prevention information
- Responsive design for mobile and desktop
- Automated CI/CD deployment

---

## Crops Covered

- Sorghum
- Wheat
- Rice
